# Live Reasoning Cards V1

VisionCore may expose a compact explanation card after semantic reconciliation without changing numeric color authority.

Customer-facing fields stay intentionally short:

- measured color / family
- appearance note
- short reason
- confidence

The deeper appearance/measurement synthesis remains internal. The live card layer cannot change measured HEX, masks, scores, ownership, or publication.

Example:

- Measured color: `#6F263D`
- Appearance: `Appears brownish burgundy`
- Reason: `Warm lighting`
- Confidence: `High`
